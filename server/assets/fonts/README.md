Fonts for the printed card (server/lib/cardPdf.js), the Latin subset of
each, as static instances from Google Fonts:

- Fraunces, opsz 9 weight 380, roman and italic (body and note)
- Fraunces, opsz 72 weight 340, italic (title)
- Fraunces, opsz 9 weight 560, roman (the spaced capitals: labels and the front's title)
- Inter, weight 500 (the label)
